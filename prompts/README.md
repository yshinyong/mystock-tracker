# Prompts

Curated prompts used for this project (or related stock analysis work), one file per prompt.

## Convention

Each prompt is its own `.md` file, named after what it does (e.g. `daily-stock-summary.md`), with a small header before the prompt text:

```markdown
---
title: Short descriptive title
source: Where this came from — a URL, "self-written", "ChatGPT", "Claude conversation 2026-07-20", a book/blog, etc.
date_added: YYYY-MM-DD
---

<the actual prompt text>
```
